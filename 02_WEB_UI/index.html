PKG Installationswege

Wähle den für dich passenden Weg: USB an der Konsole oder komfortabel vom PC.

▣

1 · USB-Stick

Der einfache Weg für einzelne oder offline gespeicherte Pakete.

1
Pakete auf dem PC bereitstellen

Im Bereich Pakete herunterladen oder eigene PKG-Dateien importieren. „✓ Offline verfügbar“ zeigt, welche Dateien lokal bereitliegen.

2
USB-Ordner bauen

Im USB Builder die gewünschten Dateien auswählen und „Sammelinstallation erstellen“ anklicken. Den INHALT des Exportordners in das Stammverzeichnis eines exFAT-Sticks kopieren; HESPERIA legt dort PKGs, Manifest und Anleitung ab.

3
Auf der PS4 installieren

GoldHEN → Debug Settings → Package Installer öffnen, Package Source auf USB stellen und „Install All“ wählen. Wenn „Install All“ fehlt, „Background Installation“ ausschalten.

⇧

2 · DirectPackageInstaller am PC

PC-Oberfläche für den Netzwerkversand; HESPERIA kann lokale PKG-Links bereitstellen.

1
Offizielle PC-App beziehen

Nur die Windows x64-Version aus den Releases des Projekts verwenden. Wenn DPI es verlangt, zusätzlich die .NET 8 Desktop Runtime von Microsoft installieren.

DirectPackageInstaller Releases ↗ · .NET 8 ↗
2
Empfänger auf der PS4 aktivieren

GoldHEN starten und entweder den Payload Server aktivieren oder die Remote Package Installer App öffnen und im Vordergrund lassen. RPI ist dafür nicht zwingend, wenn DPI den GoldHEN Payload Server verwenden kann.

3
Lokale PKG aus HESPERIA verknüpfen

In Downloads bei einer vorhandenen PKG „DPI-Link kopieren“ wählen. Den Link in DPI einfügen, laden und installieren. PC und PS4 müssen im selben privaten Netzwerk sein.

DirectPackageInstaller ist ein separates Drittanbieterprogramm und wird nicht von HESPERIA installiert. HESPERIA stellt nur die lokale Datei-URL bereit. Nur rechtmäßig bezogene Pakete verwenden.

Willkommen bei HESPERIA

Einmal einrichten – danach bequem verwalten

HESPERIA lädt Pakete auf den PC und übergibt sie im Heimnetz an eine vorbereitete PS4. Dieser Assistent führt dich durch die einmaligen Voraussetzungen.

1
GoldHEN auf deiner PS4 starten

GoldHEN muss bereits für deine Konsole/Firmware eingerichtet sein. HESPERIA führt keinen Exploit aus.

2
Remote Package Installer einmalig installieren

PKG aus einer vertrauenswürdigen Quelle beziehen, per USB mit dem normalen Package Installer installieren und RPI öffnen. Lass RPI während der Übergabe gestartet.

RPI-Paketquelle öffnen ↗
3
PC und PS4 ins gleiche private Netzwerk bringen

Oben „PS4 suchen“ klicken. Falls nichts erscheint, die PS4-IP unter Einstellungen → Netzwerk → Verbindungsstatus anzeigen ablesen und manuell eintragen.
