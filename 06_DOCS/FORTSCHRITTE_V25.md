# HESPERIA v25 – USB-Sammelinstallation verlässlich machen

- Der Sammel-Export enthält jetzt konkrete Schritte: exFAT empfohlen, Exportordner-INHALT ins USB-Stammverzeichnis kopieren, Package Source auf USB stellen und „Install All“ wählen.
- Hinweis ergänzt: FAT32 wird erkannt, kann aber keine Einzeldateien über 4 GB speichern.
- Auf der PS4 fehlt „Install All“, wenn GoldHEN „Background Installation“ aktiviert ist.
- Der Export bleibt eine Sammlung unveränderter PKGs, keine technisch ungültige zusammengefügte PKG-Datei.
- UI und Serverstatus auf v25 aktualisiert.

Die Hinweise wurden anhand der GoldHEN- und PKG-Installationsdokumentation geprüft:
- https://consolemods.org/wiki/PS4:GoldHEN
- https://consolemods.org/wiki/PS4:How_to_install_PKG_files
