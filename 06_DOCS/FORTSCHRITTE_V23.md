# HESPERIA v23 – Quellen, Paketstatus und Sammelinstallation

- Katalogquellen lassen sich live prüfen; jedes Element zeigt den ermittelten Release-/Download-Link oder den konkreten Fehler.
- pPlay wird aus dem offiziellen Projekt-Release-ZIP sicher extrahiert; die enthaltene PS4-PKG wird als installierbare und offline verfügbare Datei geführt.
- Eigene Fortschrittszeile je ausgewähltem Paket mit Status, Prozent, Geschwindigkeit und Restzeit.
- USB-Export enthält alle ausgewählten PKGs separat im Stick-Stammverzeichnis; GoldHEN „Install All“ kann diese als Stapel abarbeiten, wenn Background Installation aus ist.
- Kein ungültiges „zusammengeklebtes“ Mehrfach-PKG: jede einzelne PKG bleibt ein unveränderter, gültiger Container.
