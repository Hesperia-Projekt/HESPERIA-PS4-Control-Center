# HESPERIA v30 – USB-Ablauf und Auswahl

- Korrigiert das Downloadstatus-Raster: Paketname, Status und Fortschrittsbalken haben jetzt passende Spalten; auf schmalen Fenstern stapeln sie sich.
- „Alle auswählen“ und „Auf USB-Stick schieben“ stehen direkt oben in der Paketauswahl, vor der langen Paketliste.
- Bulk-Auswahl gilt für aktuell sichtbare und installierbare Pakete und kann mit „Auswahl aufheben“ zurückgenommen werden.
- USB-Aktion lädt fehlende ausgewählte Pakete automatisch und erstellt anschließend den Exportordner mit Manifest und Installationsanleitung.
- USB-Ansicht erklärt jetzt die drei Schritte: Stick formatieren/einstecken, Exportordner-Inhalt ins Stick-Stammverzeichnis kopieren, PS4 Package Installer → USB → Install All.
- Der USB-Ordner öffnen-Button erklärt, dass Explorer auf dem PC mit HESPERIA startet; er zeigt Pfad und nächsten Schritt im Statusfeld an.
- Klargestellt: Mehrere separate PKGs lassen sich nicht zu einer einzelnen Sammel-PKG verschmelzen; der Export ist für Install All gedacht.
