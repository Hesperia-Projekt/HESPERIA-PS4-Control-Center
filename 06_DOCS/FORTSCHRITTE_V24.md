# HESPERIA v24 – Sammelinstallation für USB

- Neuer sichtbarer „Sammelinstallation erstellen“-Ablauf im USB Builder.
- Exportiert alle ausgewählten, lokal verfügbaren PKGs unverändert ins USB-Stammverzeichnis und erzeugt Anleitung/Manifest.
- Die Anleitung erklärt GoldHEN Package Installer → „Install All“ (Background Installation vorher ausschalten).
- Die UI unterscheidet ausdrücklich zwischen einer Install-All-Sammlung und einer einzelnen PKG-Datei.
- Mehrere unabhängige Apps in ein einziges gültiges PS4-PKG umzupacken wird nicht vorgetäuscht; Merge-Tools setzen ausschließlich Teile desselben Pakets zusammen.
